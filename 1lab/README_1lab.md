# Лабораторная работа 1: Базовая инициализация DirectX 11

## **Техническое задание**
1. Создать оконное графическое приложение.
2. Проинициализировать DirectX 11.
3. Заливать фон фиксированным цветом (синий) на каждом кадре.
4. Обрабатывать изменение размера окна (`WM_SIZE`) с пересозданием `SwapChain`.

---

## **Описание реализации**
- Окно создаётся с помощью **WinAPI**.
- **DirectX 11** инициализируется с использованием `D3D11CreateDeviceAndSwapChain`.
- Экран заполняется фиксированным синим цветом через `ClearRenderTargetView`.
- **Обработано изменение размера окна**:  
  При `WM_SIZE` вызывается `ResizeBuffers()`, а затем создаётся новый `RenderTargetView`.

---

## **Запуск приложения**
Приложение автоматически собирается с помощью `build.bat`.  

### **Шаги для сборки и запуска:**
1. Откройте `build.bat` (двойной клик) **или запустите через командную строку**:
   ```sh
   build.bat
   ```
2. Дождитесь сообщения "Build successful!".
3. Запустите DirectXApp.exe:

```sh
   src\DirectXApp.exe
```
