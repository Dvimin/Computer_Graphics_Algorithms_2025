# Лабораторная работа 1: Базовая инициализация DirectX 11
### **Техническое задание**
1. Создать оконное графическое приложение.
2. Проинициализировать DirectX.
3. Заливать всё фиксированным цветом на каждом кадре.
4. Поддержать изменение размера окна (пересоздавать рендер-таргет при получении сообщения `WM_SIZE`).

---

### **Описание реализации**
- Приложение создаёт окно с помощью WinAPI и инициализирует DirectX 11.
- Экран заполняется фиксированным цветом (синий) с помощью `ClearRenderTargetView`.
- Обработано сообщение `WM_SIZE`, которое изменяет размер `SwapChain` и пересоздаёт рендер-таргет.
